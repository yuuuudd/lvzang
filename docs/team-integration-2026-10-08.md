团队入口：https://lvzang.gzaibuilders.cn/portal.html 。使用原共享账号；凭据由账号持有人通过私密渠道提供。使用同一账号可在不同浏览器访问同一作品库和订单，刷新读取队友的更新。旅行问卷与路线仍按账号保存在各浏览器，路线编辑不提供跨设备同步。原浏览器独有旧作品仍需导出 ZIP 并导入公网，见 lvzang-server-library.md。

开发同步：先保存个人改动，再切换 main 并 git pull --ff-only origin main。Node 24.5+，npm ci，复制 .env.example 为 .env 并填写自己的运行配置，npm start。不要提交 .env、output 或账号凭据；不要把旧分支直接覆盖 main。
