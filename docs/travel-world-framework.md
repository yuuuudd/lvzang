# 旅行世界框架：2026-10-05

最新用户指令优先：按自由画布/时间轴/地图概念搭框架，添加旅行回忆入口加大，照片、冰箱贴与微缩作品使用简单图形占位，不调用真实生成。

入口：`/collection.html?demo=1#world/canvas`。原收藏版保留在 `/collection.html?legacy=1`，原数据不清理。

## 可操作内容

- 自由画布默认入口；同一批旅行切换时间轴和地图。
- 空白处拖动平移，滚轮或按钮缩放；查看全部根据实际布局取景。
- 整理模式可拖动旅行组及作品；选中作品后旋转、调整大小和层级，布局保存到独立IndexedDB元数据；时间轴/地图不改自由位置。
- 点击作品展开侧栏；回忆与定制各自打开独立弹窗。照片和3D形态仍为占位，不声称已经建模。
- 大号黄绿色“添加旅行回忆”：上传1—4张照片；一句故事和地点可选；选择个人记忆或城市风景；先保存照片与占位作品。
- 完整备份包含照片和自由布局；恢复不覆盖已有布局。示例重置只整理示例，保留个人位置。
- 同城多次旅行保留独立ID，地图聚合可逐段选择；没有可靠城市位置的作品放到待确认地点列表。
