# 定制产品规则：冰箱贴与摆件

用户确认的方向：客户定制时先选择冰箱贴或摆件，再与受经营者规则约束的 AI 沟通。产品类型决定参考图、修改、三维处理和制作检查。产品选择、类型与版本保存、参考图约束、三维产品处理、审核和交付校验已接入现有定制流程；实体切片与试打仍需经营者完成。

## 共同流程

选择产品 → 提交照片与想法 → AI 补充必要问题 → 生成参考图 → 客户修改与确认 → 生成三维 → 按产品规则处理与检查 → 展示生产版本 → 确认交付。

- 产品类型必须由客户明确选择；AI 不根据照片自行猜测产品类型。
- 问答用于补充影响制作的信息；信息足够时生成初稿。普通问答不强制调用生图。
- 客户修改外观时，以当前选定参考图为依据生成修改图，并说明修改内容；保留之前的版本。
- 客户确认参考图后才进入三维生成。实体生产须另外满足工艺检查与经营者放行条件。
- 产品类型、实际尺寸和生效的制作规则随需求、任务、参考图和模型保存；修改和恢复任务使用同一组规则。
- 产品类型变更时保留原作品，重新确认新产品的设计；原有确认记录不能用于新类型。
- 客户预览、生产检查和交付必须对应同一版本的处理后模型；原始生成模型作为来源保留。

## 两套产品规则

| 环节 | 冰箱贴 `magnet` | 摆件 `figurine` |
| --- | --- | --- |
| 必要信息 | 来源主体、正面构图、成品尺寸、风格；磁铁与工艺规格由经营者提供 | 来源主体、姿态、成品尺寸、风格、是否需要底座；重要背侧细节不足时追问 |
| 首张参考图 | 正面为主、略带侧视的单件产品效果图，轮廓和立体层次清楚，主体紧凑相连 | 单件完整立体造型的三分之四视角效果图，展示体积、姿态、接地点和底座关系 |
| 参考图限制 | 不把画面做成海报；不画与主体分离的薄片、无支撑细枝或突兀背景墙；磁铁孔由程序生成 | 不按冰箱贴的贴背构图限制造型；避免无支撑细长肢体、漂浮附件和不合理接地点；底座仅在需要或已约定时加入 |
| 修改规则 | 保持产品类型、已确认主体及事实；根据修改意见调整正面造型、层次和轮廓 | 保持产品类型、已确认主体及事实；根据修改意见调整姿态、体积、四周造型和支撑关系 |
| 三维生成 | 正面造型用于生成原始立体模型；背面、磁铁安装结构和准确尺寸另行构造 | 生成可从四周查看的完整模型；隐藏细节按客户资料或明确约定处理 |
| 几何处理 | 确认正面方向，保留正面立体造型，构造沿轮廓的平背与可安装磁铁的结构；处理位置须避免损伤主要造型 | 保留完整背部；按约定构造平稳接地面或底座，检查接地范围和重心；不得沿用冰箱贴的背板与磁铁孔处理 |
| 客户确认预览 | 处理后的正面、侧面和背面；可见尺寸、总厚度及磁铁安装方式 | 处理后的旋转预览，补充背面和底部；可见尺寸、底座及摆放方式 |
| 产品专属检查 | 安装接触面平整、磁铁孔尺寸与孔底厚度、安装件是否突出、总厚度及磁吸装配试验 | 接地面、底座连接、重心与站立稳定性、细长件强度及摆放试验 |

所有厚度、孔径、公差、尺寸范围与材料限制来自经营者配置的工艺规格；不得让 AI 自行承诺统一数值。几何尺寸可由程序固定，实际装配公差需要按设备、材料和试打结果校准。

## 生图约束模板

以下约束由程序按客户所选类型附加，客户自然语言修改不能移除必要的制作规则。主体、事实和风格取自本次需求，不用模板编造。

**冰箱贴**：制作一枚独立的立体冰箱贴设计参考图。以正面为主，略带侧视，展示主要轮廓和立体层次。主体紧凑、厚实且相连；背部为后续平背处理预留空间。避免分离薄片、细碎悬空附件和独立背景墙。纯净背景，展示单件产品；不生成磁铁孔和尺寸标注。保持客户指定主体、姿态、颜色与风格。

**摆件**：制作一件完整立体摆件设计参考图。使用三分之四视角，展示完整主体、体积、姿态及与地面或底座的接触。造型从四周查看应合理，细小附件需要可靠连接或支撑。底座按已确认需求处理，纯净背景，展示单件产品，不添加磁铁孔或冰箱贴背板。保持客户指定主体、姿态、颜色与风格。

## 制作放行

- 两类产品都检查实际尺寸、封闭性、连通性、薄壁、悬空与支撑，以及目标打印工艺能否实现配色。
- 未执行的检查显示“待检查”；不能用模型生成成功、文件导出成功或没有失败项代替实际验收。
- 展示阶段分别记录：参考图已确认、三维几何已检查、切片已检查、试打已验证。
- 无法可靠处理的模型进入经营者待办；不能静默修改主要外观后直接生产。
- 实体交付需有实际生产与验收记录；数字文件交付记录其检查范围和未完成的实体验证。

## 接入现有流程时的核对项

- 客户入口首先选择产品；订单与经营者详情显示同一类型。
- 参考图初稿和修改都加载对应类型的约束。
- 现有创作入口、订单往返和生成任务恢复均保留产品类型。
- 冰箱贴采用项目已有平背/磁铁孔处理能力，并补齐可测量的平整度检查；保存并预览处理后的生产模型。
- 摆件不使用磁铁背板；底部、支撑和稳定性检查需要单独实现，不能把现有无孔模式直接标为摆件验收通过。
- 旧作品缺少类型时保留原数据；进入新的实体定制前由客户或经营者明确类型。

最小验证：同一张照片分别建立冰箱贴与摆件定制，核对参考图方向、修改时的类型保留、三维结构、专属检查及最终交付文件。
