# 拾光：让旅行记忆拥有形状

> **产品介绍与发展愿景**  
> 文档版本：2026 年 9 月 24 日  
> 当前产品：可交互的旅行回忆画、单件立体纪念物生成与打印文件导出

## 一句话介绍

拾光是一款面向旅行者与文旅场景的 AI 记忆创作产品。它从真实照片和用户亲述的一段故事出发，把旅行中的人、物和场景组织成可点击的回忆画，并进一步生成可旋转查看、可导出的立体纪念物，让一次旅程不只留在相册里，也能成为一件可以重新打开、讲述和制作的个人作品。

## 产品愿景：旅行结束后，记忆还可以继续生长

人们带着照片离开一个地方，却很少带走真正属于自己的纪念品。常见纪念品记录的是景点的标准形象；手机相册保留了大量影像，却缺少把这些影像编成个人故事的方式。拾光希望连接这两端：从游客真实经历出发，生成属于某一个人、某一段关系、某一次旅行的文创作品。

长期来看，拾光希望成为旅行记忆的创作与呈现入口：照片是记忆的证据，故事补上照片之外的意义，AI 帮助整理与表达，数字作品保存创作结果，实体制作让记忆进入日常生活。用户可以从一张照片开始，也可以将一次旅行逐渐整理成由许多记忆点组成的个人作品集。

这个愿景的核心不是“用 AI 画一张好看的图”，而是让作品始终能够回答三个问题：它来自哪一刻？为什么对这个人重要？它如何变成一种可以带走的形式？

## 用户遇到的问题

### 纪念品有地点，却少有个人经历

景区商品通常围绕地标和统一图案设计。它们能让人认出“去过哪里”，却不一定能表达“和谁去的、那天发生了什么”。个性化定制往往需要用户自己找图、排版、沟通设计，制作门槛高，也难以现场完成。

### 相册有照片，却没有顺手的讲述方式

一段旅程可能留下数百张照片。照片能保存画面，却未必说明同行者之间的关系、拍摄前后的故事，或某个瞬间为何值得记住。照片越多，回看的成本反而越高。

### AI 生成容易漂亮，却容易失去真实依据

只靠一句提示词生成的旅行画，可能添加用户没有经历过的人物、动作或地点。纪念作品如果和真实记忆脱节，就会变成一张泛化的 AI 图片。

### 数字图像到实体制作之间存在落差

一张插画并不自动等于一个可制作的三维物件。轮廓、厚度、细节、连接和背面都会影响模型是否适合继续加工。用户需要看到制作过程中的真实限制，而不是只看到渲染图就被告知“已经可以打印”。

## 产品主张

**以真实记忆为起点，以用户确认作为创作边界，让 AI 把记忆变成可继续编辑的作品。**

拾光的 Agent 能力是产品的核心技术特色，也对应 Agent 赛道的参赛方向。系统把创作拆成一组有明确目标的智能任务：理解照片与故事、提出记忆点、调用图像分割工具、组织生成素材、生成参考图、回看结果、按实测几何报告选择后续操作。每个智能体围绕具体任务产出结构化结果，后续步骤使用这些结果继续工作，用户可以在关键节点检查并决定是否继续。

拾光遵循四个原则：

1. **真实材料优先。** 照片决定可见的人、衣着、物件与画面线索；故事补充照片之外的关系、动作与情绪。没有依据的地标和经历不应被伪装成事实。
2. **用户保留决定权。** AI 提供构思、生成图和回看建议；用户可以检查、修改、重绘，再决定是否进入三维制作。
3. **每一步都能看懂。** 从输入依据、创作构思到生成参考图和几何检查，尽量展示结果来自什么、当前完成到哪里、还有什么需要人工判断。
4. **数字结果和实体边界说清楚。** 图像、参考图、三维网格和打印文件是不同阶段的产物。模型检查通过不等于已完成切片、打印或实物验证。

## 产品体验

### 路径一：把一次旅行整理成可探索的回忆画

用户建立旅行合集，添加 2 至 9 张照片，可以填写旅行名称、地点、日期和整趟旅行的故事。AI 逐张分析照片，为每张照片提议一个有画面依据的记忆点，并标出实际可见依据。用户可以编辑标题和记忆故事，检查主体是否选对。

系统在本机使用图像分割模型提取照片中的人物、物件或场景，再将这些元素组织成参考导图。用户触发生成后，图像模型把导图重绘为一张统一风格的横向旅行插画。之后系统分析生成画，为各个记忆点定位可点击区域；定位不确定时可以手动修正。

用户点击画中的元素，可以回到它对应的原照片、故事和纪念物。旅行画因此不仅是一张合成图，也成为浏览一段旅行的入口。

### 路径二：把某一个记忆点做成立体纪念物

用户从合集的某个记忆点进入单件创作，系统带入该点的来源照片、故事，以及合集地点和日期。也可以直接上传一张照片，在单件创作入口开始。

用户选择插画或雕塑风格，并可选用主题预设。AI 结合照片、故事与预设形成创作构思：提炼关键元素，安排主体、动作和空间关系，生成面向图像生成的具体提示词。随后图像模型生成单件参考图。系统再把参考图与来源照片、故事和场景做视觉回看，列出检查结果或修改建议。

默认的半自动流程会在参考图阶段暂停，让用户检查并决定是否进入三维建模。全自动流程可在回看成功后继续建模与本地几何检查。完成后，用户可以旋转查看数字模型、检查制作记录，并按支持情况导出 STL 或带颜色信息的 3MF。

### 路径三：查看、调整并交付制作文件

用户可以查看创作参考图和三维模型，继续调整制作参数，并直接导出支持的打印文件。STL 可用于几何打印流程；带颜色信息的 3MF 可在兼容软件中继续检查和切片。文件导出让产品从数字创意进入实体制作交付，实际打印前仍需在切片软件核对尺寸、支撑、耗材和成本。

## 故事、照片与 AI 各自做什么

| 输入或系统 | 在创作中的作用 |
| --- | --- |
| 来源照片 | 提供可见主体、人数、姿态、服饰、物件和场景线索；限制构图必须尊重的视觉事实。 |
| 这一刻的故事 | 补充人物关系、动作、事件和情绪，帮助系统理解这张照片为何值得纪念。故事选填；只有照片也可以开始。 |
| 地点与日期 | 作为用户明确提供的上下文进入构思和作品记录；地点需要和参考图构思保持一致。 |
| 主题预设 | 提供明确选择的活动、场地或角色资料；不会在未选中时自动套用。 |
| 拾光 Agent 工作流 | 编排图像理解、记忆策展、工具调用、生成、视觉回看和制作检查，让创作任务跨步骤推进。 |
| DeepSeek | 在旅行策展、故事理解、设计构思及生成图回看等环节提供结构化建议。 |
| Tripo | 根据文本与图像参考生成旅行插画或单件创作参考图，并从单件参考图继续生成三维模型。 |
| 本机图像分割与几何处理 | 分割旅行照片中的记忆元素，处理预览、尺寸调整、模型检查和部分导出流程。 |

故事不会直接变成立体几何。它先参与参考图构思和图像生成；建模阶段读取的是用户确认后的参考图。用户若希望故事内容改变模型外观，需要修改故事或修改意见并重新生成参考图，再检查新结果。

## Agent 能力：理解任务、使用工具、检查结果、推进下一步

拾光面向 Agent 赛道的关键能力，是让 AI 参与有状态的多步骤创作流程：它需要结合上下文作出受约束的决定，调用真实工具完成子任务，再根据工具的返回结果决定如何继续。用户看到的是一条从照片与故事到回忆画、参考图和打印文件的连贯工作流；内部则由不同职责的智能步骤和确定性工具共同完成。

### 1. 感知并整理多模态输入

记忆策展 Agent 同时读取旅行信息和多张照片，为每张照片提出一个片段、标题、可见依据与分割目标。它需要保持照片与记忆点的一一对应；没有用户故事时，只能基于照片中能看到的内容写草稿，不能把推断出来的关系和经历冒充事实。

### 2. 把自然语言转成可执行构思

创作 Agent 将故事、照片、地点、风格和已选主题整理成构思摘要、关键元素、动作与空间安排，以及可用于生图的具体提示词。服务端校验结构、字段和长度，也核对用户指定地点等约束，确保后续生成环节拿到可执行、可检查的输入。

### 3. 调用专业工具完成感知与生成

Agent 工作流会把合适的子任务交给专用工具：本机分割模型提取照片主体，图像生成服务绘制旅行回忆画或单件参考图，视觉模型寻找生成画中的对应元素，三维服务把用户确认后的参考图转成模型。本机几何工具再检查网格并准备打印文件。

### 4. 用视觉回看和测量结果形成反馈

回看 Agent 对照来源照片、故事、创作构思与实际生成图，逐项报告符合、存在问题或无法确定的内容。旅行画定位 Agent 为每个记忆点寻找画面区域；只有识别到可靠目标后才生成点击区域，定位不稳时允许重试定位或由用户手动校准。

在结构实验模式中，结构 Agent 先选择受限的参数化构图，再读取实际几何检查报告，决定接受、简化、加粗或停止。工具执行后会重新检查，并保存模型版本和决策轨迹。自动修正最多一次；遇到无法可靠修复的模型会停止交付。这个参数化结构实验模式属于开发选项，不是默认的故事创作路径。

### 5. 让用户掌握高影响决策

Agent 可以准备构思、请求生成、回看和提出下一步建议；是否重绘参考图、是否开始三维建模，以及是否接受导出结果，仍由用户控制。默认半自动模式会在参考图和回看完成后暂停，用户确认后才继续付费建模。全自动模式也只会在回看成功后进入建模；几何检查失败时不会把作品标成可导出。

### Agent 工作流的可核对输出

- **任务输入：** 原照片、用户故事、地点、日期、风格与明确选中的预设。
- **决策结果：** 记忆片段、设计 brief、主体与构图、定位区域或修正动作。
- **工具产物：** 分割素材、生成图、三维模型、几何检查报告与可导出文件。
- **反馈信息：** 构思依据、回看检查、工具执行记录、模型版本与停止原因。
- **用户控制点：** 编辑记忆故事、修正定位、修改构思、确认参考图及决定后续制作。

这让 Agent 的价值可以从任务是否完成、工具是否正确调用、结果是否通过核对、异常时能否安全停止等方面评估，而不只看文本回答是否流畅。产品当前已经包含上述多阶段 Agent 工作流和受限结构决策实验；更广泛的跨任务自主规划、长周期记忆与自动经营收藏馆仍属于未来研究方向。

## 产品能力一览

### 当前版本已具备

- 创建旅行合集，保存旅行信息、照片与单张照片对应的记忆点。
- 对多张照片提出有依据的记忆片段建议，允许用户修改故事与标题。
- 在本机提取人物、物件或场景，生成统一旅行回忆画。
- 自动定位画中的记忆元素；提供重新定位和手动修正入口。
- 从某一张照片与故事生成单件纪念物参考图，并查看创作构思。
- 选择多种视觉风格；支持一个主题活动预设。
- 对参考图执行视觉回看，支持半自动确认或受控的全自动后续流程。
- 从参考图生成三维模型，进行本地尺寸、封闭性、连通性、颜色和悬空等检查。
- 通过多阶段 Agent 工作流连接视觉理解、记忆策展、工具调用、生图、回看与后续制作；在结构实验模式中依据实测检查决定有限修正或停止。
- 交互式查看作品、调整制作参数，并在支持的模式下直接导出 STL 或 3MF 打印文件。

### 当前版本的边界

- 旅行回忆画和部分三维服务会调用第三方 AI 接口，主动生成会消耗相应平台额度。
- 图像分割在本机执行；照片和故事在用户发起相关 AI 功能时会发送到对应云端服务。
- 自动图像回看与几何检查只能覆盖已实现的检查项。不能保证地标完全准确、人物细节完全忠实、所有结构适合打印，也不能代替人工视觉复核、切片和试打。
- 参考图生成与三维建模是分阶段任务；不是每一种输入都能稳定生成满足实体制作要求的模型。
- 颜色化 3MF 是模型表面涂色数据，不等于自动分色的可拆装零件。STL 本身不保存颜色。
- 作品文字生成对中文精确排版仍有限制。默认立体故事创作的参考图不添加文字或名牌；旅行回忆画的标题和票根文字也需要核对实际生成效果。
- 旧记录、旧模式与新版故事创作的加工能力不同。模型导出后仍应在切片器中核对尺寸、支撑、耗材和打印结果。

## 目标用户与使用场景

### 个人旅行者与同行者

用户希望把和家人、伴侣、朋友或独自旅行中的某个瞬间做成纪念品。故事输入可以很短，不需要写成完整游记；一两句关于“和谁、在哪儿、做了什么”的信息，就能给照片增加创作方向。

### 旅行组织者与内容创作者

导游、旅行社、博物馆讲解员或创作者可以用回忆画把分散的照片组织成一段可浏览、可讲述的旅程。记忆点把画面与照片、故事连接起来，便于现场演示或共同回顾。

### 文旅目的地与文化机构

目的地可以围绕明确的活动、展览或地方文化主题设计创作预设，让游客的真实照片与个人经历成为文创的主体。预设应提供背景资料与风格约束，不应覆盖用户输入的个人事实。

### 文创设计与制作团队

设计师和制作人员可以把拾光作为概念生成、参考图审查和制作前处理的辅助流程，快速从游客素材进入可讨论的设计稿，再由人来确定文化准确性、工艺可行性和最终质量。

## 价值与差异

### 从“目的地商品”转向“个人记忆作品”

相同的目的地可以对应不同的人、关系与故事。拾光让纪念品从统一地标图案延伸到具体个人经历，使“这是什么地方”与“我在这里经历了什么”同时出现在创作中。

### 从相册浏览转向记忆导航

旅行画中的元素与来源照片和故事相连。用户可以沿画面进入不同片段，而不是只按时间顺序翻看图片。每个作品成为一条回到记忆现场的路径。

### 从一次生成转向可检查的创作过程

拾光保留构思、参考图、回看、三维和检查记录。AI 生成不是黑箱式的“给出一张图就结束”，用户可以在关键环节看依据、提出修改，再选择后续制作。

### 从平面表达延伸到实体制作

同一条创作链能够从照片与故事走到插画、三维预览和文件导出，连接个人表达与实际制作。实体结果仍需专业检查，但数字创作不再停留在不可编辑的图片上。

### 把真实性作为产品能力

照片提供视觉事实，故事提供用户自己的意义，地点和主题预设提供显式上下文。系统的任务是组织并表达这些材料，而不是擅自替用户补写经历。对记忆产品来说，知道哪些内容不确定，与生成内容本身同样重要。

## 产品体验原则

1. **先保存记忆，再生成作品。** 输入照片、故事和地点应能成为可继续编辑的材料，不要求用户一次填完所有信息。
2. **具体瞬间优先于空泛主题。** “我们三个人毕业前在校门口拍照”比“青春旅行”更能引导有辨识度的构图。
3. **让照片和故事互相补充。** 照片决定看得见什么，故事解释画面之外的关系和情绪；发生冲突时应提示用户确认。
4. **生成结果必须允许核对。** 画面里的关键人物、动作、地点和活动元素需要能与输入或预设对照。
5. **创作与制作分阶段。** 用户先确认创意和参考图，再决定是否消耗额度进行三维建模。
6. **对失败和不确定诚实。** 任务失败、定位不准、检查未通过或无法确认的视觉细节，都应明确显示并保留可恢复的工作。
7. **由用户决定作品何时完成。** 一张图片可以作为数字纪念作品；三维建模与打印是可选择的下一步。

## 可拓展方向：赛博文创收藏馆

在当前的旅行记忆创作和打印文件交付能力之上，未来可以向“赛博文创收藏馆”拓展：把数字作品、创作故事和实体纪念物连接起来，形成可持续浏览、展示、分享和再创作的线上收藏空间。这是一个可发展的产品方向，不是当前版本的主线或已上线功能。

### 个人数字收藏空间

未来可把用户授权保存的旅行合集、单件作品和创作过程组织成长期可浏览的个人收藏。用户可以按旅行、人物、地点、时间或主题回看作品，看到同一段记忆从原照片到插画、模型和实体的变化。

### 多人共同创作

同行者可以为同一段旅行补充自己的照片和故事，共同确认记忆点，最终制作一张包含多个人视角的旅行画。不同叙述可以并列保留，不必强行合并成唯一版本。

### 目的地创作模板

文旅机构可以提供经过核实的地点资料、文化元素和活动素材。游客仍从自己的照片与故事开始，预设负责提供准确背景，AI 负责将二者组合成个人化作品。

### 线上收藏与线下体验连接

未来可探索将作品以二维码、数字页面或现场展示方式分享，使实体纪念物能够链接回照片、故事和旅行画；也可探索展馆、景区和活动现场的互动创作体验。分享、AR、多人同步和现场部署仍需独立设计与验证。

### 更丰富的实体品类

不同记忆适合不同的承载方式：平面纪念品适合保存完整画面，钥匙扣适合随身携带，立体摆件适合呈现人物与场景。未来可在完成结构、尺寸、连接和工艺验证后，逐步支持更多明确的产品类型，避免仅靠切换导出格式来假装完成品类适配。

### 从生成到可交付制作

更成熟的制作链可以包含可解释的结构检查、切片预估、颜色与耗材建议、打样记录及实物反馈。长期目标不是承诺“一键打印必成功”，而是逐步缩短从个人创意到可靠制作之间的距离。

## 商业模式：服务 B 端，也直接服务 C 端

拾光既可以作为文旅机构的创作与商品服务，也可以直接面向游客销售个性化作品。两种模式共享照片与故事驱动的创作能力、参考图生成和打印文件交付，但服务对象、购买决策与交付方式不同。

### B 端：面向文旅机构提供可落地的文创方案

潜在客户包括景区、文博场馆、文旅集团、主题活动主办方、旅行服务商和文创品牌。拾光可以向 B 端销售：

- **定制化创作系统：** 按目的地、展览或活动配置主题、素材和创作流程，让游客从个人照片生成专属纪念设计。
- **活动与现场服务：** 为节庆、展览、赛事、研学或品牌活动提供互动创作体验与现场内容方案。
- **文创设计与数字交付：** 为机构生成经确认的主题设计、系列视觉内容和可用于后续制作的打印文件。
- **定制商品与制作服务：** 围绕机构品牌或目的地主题，提供个性化纪念品设计、文件交付，或结合合作制造方完成实体商品交付。
- **项目运营与内容更新：** 按项目提供主题配置、素材维护、活动运营支持和阶段性效果复盘。

B 端的价值在于把统一的目的地资源转化为游客自己的记忆作品，为传统文创增加参与感和个性化，并为景区、场馆或活动提供可展示、可体验、可延展的服务入口。具体可采用项目定制费、系统服务费、活动服务费、设计制作费或按订单结算；定价需根据部署、运营和供应链成本验证。

### C 端：面向游客直接售卖个性化纪念品

游客可以直接购买个性化数字创作或实体纪念品：上传照片、讲述故事、确认设计，购买生成服务或打印成品。可以探索的商品形态包括数字纪念作品、定制打印文件、实体磁贴或摆件，以及围绕旅行、亲友和重要时刻设计的系列商品。

C 端的价值在于让消费者直接为“这件作品属于我的记忆”付费，而不是只能从现成商品中挑选。销售可以通过线上商城、目的地现场入口、活动页面或与旅行服务联营的渠道完成。产品应清晰标示数字文件、代打印服务和实体商品的区别，并在下单前让用户确认设计、尺寸、材料、价格和交付时间。

### 双边模式如何互相带动

B 端提供目的地内容、场景入口和稳定客流；C 端购买行为验证哪些记忆主题和商品形态真正有吸引力。成熟的 B 端项目可以沉淀可复用的主题模板，降低后续创作成本；C 端用户作品和反馈则能帮助优化模板与商品设计。机构合作不应抹去消费者的个人表达，面向消费者的直售也不依赖某一个景区才能成立。

### 商业化验证重点

- 游客愿不愿意为个人故事驱动的设计付费，数字作品与实体商品各自的购买意愿如何。
- 从生成到确认、下单和交付的链路是否足够清楚，生成费用、人工修正和制造成本是否可控。
- 文旅机构是否愿意为现场体验、主题内容和可转化的文创销售采购服务。
- 主题模板能否复用，同时保留足够的个人化；授权素材和目的地内容能否持续、合规更新。
- 打印文件与实体商品的质量、生产周期、退换和售后责任如何落实。

## 产品发展路线建议

### 阶段一：让核心记忆链稳定、可信

持续提升故事与照片之间的依据对应、旅行画记忆点定位、参考图检查与任务恢复能力。重点衡量用户能否顺利从真实照片到一件自己认可的数字作品。

### 阶段二：验证 B 端项目与 C 端直售

选择少量文旅活动或目的地场景验证 B 端采购和现场创作；同时测试 C 端线上或现场直售，比较数字文件与实体成品的付费意愿、交付成本和复购可能。根据真实订单完善下单、支付、生产和售后流程。

### 阶段三：让文旅内容可配置、可核验

形成目的地预设的资料管理与版本流程，记录内容来源、适用场景和授权状态；使景区主题能够复用，同时保留游客个人记忆的主导地位。

### 阶段四：逐步扩展实体类型、制作保障与赛博收藏

按具体品类定义构图、结构和制造约束，先通过样件与切片验证，再向用户开放生成。持续收集实物质量反馈，将可打印性从生成后的补救提升为创作阶段的设计约束。在业务与内容成熟后，再评估建设赛博文创收藏馆，将用户授权的数字作品、实体商品和记忆故事连接成线上展示与收藏体验。

## 如何衡量产品做得好不好

拾光的核心指标不应只看生成了多少张图，还应看作品是否真正对应用户的记忆、用户是否愿意继续保留它，以及从数字创作到实体制作的过程是否透明。

可逐步观察以下指标：

- **创作完成率：** 用户从导入素材到获得可查看作品的比例。
- **记忆点确认率：** 用户保留、编辑或删除自动提议记忆点的情况，判断策展是否贴合照片。
- **参考图认可率：** 用户直接确认、修改后确认或放弃参考图的比例。
- **真实性问题率：** 用户报告的错误人物、动作、地点或无依据元素数量。
- **制作推进率：** 选择继续生成三维、完成模型查看和导出文件的用户比例。
- **实体验证反馈：** 切片问题、试打成功率、返工原因和用户对实物的满意度。
- **记忆回访率：** 用户在创作后再次打开旅行画或已购作品的频率。
- **成本与耗时：** 每条成功创作链的 AI 额度、等待时间和人工修正成本。

指标需结合用户访谈和作品抽查理解。高生成量不必然等于高记忆价值；制作推进率也不能以隐藏失败、压缩核对步骤为代价。

## 隐私、内容与信任

照片与故事是个人记忆素材。当前产品在用户发起对应 AI 功能时，才把相关照片、导图或生成图发送到所需的第三方服务；图像分割在本机执行。若未来建设线上收藏馆或交易服务，应让用户清楚选择作品、照片和故事的保存与展示范围，并提供删除、导出和撤回分享的方式。

产品后续扩展时，应继续明确素材会发送给哪项服务、用于哪一步、作品保存在哪里、用户如何删除或导出。涉及目的地预设的文化内容、品牌标识或角色素材，应明确来源与使用权限。系统生成的关系、经历和地点不能标成用户事实；不确定的内容要允许用户纠正。

## 产品形态与技术概览

当前产品是本地运行的 Web 应用，包含专业版和简洁版界面。浏览器负责素材录入、画布交互和三维预览；本地 Node 服务负责校验请求、保护 API 密钥、调用 AI 服务和管理云端任务；部分图像分割与网格处理在本机执行。直接导出的打印文件可以交给用户或后续制作服务继续处理。

主要能力链路如下：

```text
照片与故事
    ↓
记忆点策展与用户编辑
    ↓
本机提取元素／组织参考素材
    ↓
旅行回忆画或单件创作参考图
    ↓
视觉回看与用户确认
    ↓
可选三维生成与本地几何检查
    ↓
作品预览、打印文件导出与交付
```

每个环节都有独立产物。旅行画适合汇总和浏览一次旅程；单件参考图适合表达一个记忆点；三维模型和导出文件则面向后续制作。它们共同组成创作路径，但不应混为同一种输出。

## 对外介绍短版

拾光是一款由多阶段 Agent 工作流驱动的旅行记忆文创产品。Agent 从真实照片与故事中整理记忆点，调用分割、生图、视觉回看和三维制作工具，把一次旅行变成可点击的回忆画，或把某一刻继续做成立体纪念物并导出打印文件。照片提供真实画面，故事补充人物关系与经历；用户可以检查构思、确认参考图并决定下一步。拾光希望让纪念品记录的不只是“我去过这里”，还有“这是我在这里经历的那一刻”。

## 一句话愿景

**让每一段值得记住的旅行，都能成为一件有来处、有故事、可继续生长的作品。**
