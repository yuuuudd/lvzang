# 经营者工作台：实现与验证

日期：2026-10-06。

## 使用入口

本机实际服务：`http://localhost:4181/operator.html`。旅行页增加“经营者工作台”，个人合集及单件详情增加委托入口。工作台内可从新照片、已有作品或旧定制需求开始；来源默认团队自测。

## 已实现

- 同一委托的需求与素材、制作、审核、交付步骤；来源、负责人、状态、费用、人工时间、备注与反馈记录。
- DeepSeek 需求摘要、实际检查报告摘要、交付说明；未知情况留待确认，失败保留原内容，允许人工填写。
- 从个人作品/合集发起委托；旧定制需求可以转换，原记录保留。
- 单件创作使用现有拾光流程，带入源照片和需求，默认半自动；参考图、三维结果自动关联回原委托。
- 参考图/三维任务返回编号后写入本机委托；重新打开同一委托可继续领取原任务。未完成任务不会因重新打开而自动新提交。
- 需求、选中作品版本和审核绑定；需求/作品更新后需要重新审核。打印限制不影响符合要求的数字作品交付，但不能宣称实体验证完成。
- 只读客户预览和按本委托筛选的 ZIP；不含其他委托、内部备注、成本；原照片默认不加入。
- 文件导出与实际交付分别记录；取消手机分享不算已导出。客户实际交付由经营者手工记录。
- 经营备份/恢复；包含本机委托和完整收藏，供经营者保存；仅有参考图的阶段也可恢复，不伪造 GLB。
- 桌面及390px手机布局、键盘焦点、隐藏控件与状态文字。

## 设计中的实施取舍

- 首版专注一件数字作品完整交付；多件合集可挑选作品，不新写生成引擎。
- 创作需求原文完整保留；进入现有单件工具时使用300字内摘要和12字内地点名，超过限制时显示说明，可在创作页核对编辑。
- 经营备份包含整个本机收藏，客户交付包严格按选定委托筛选；两者文案与用途分开。
- 程序记录工具提交、保存、审核、导出等事件；人工工作时间和实际API费用手工记录。没有做供应商账单同步、营收统计或自动提效百分比。
- 活动沿用现有商家区域入口；新推广文案、通用模板、远程账号、支付、生产与物流留到后续。

## 验证

- 全部单元/API检查：215项通过，0失败。日志 `artifacts/operator/unit-tests.log`。
- `tests/operator.browser.js`：真实IndexedDB、作品选择、需求摘要适配器替身、审核、客户预览隐私、实际ZIP下载、手工交付、刷新与桌面/手机。
- `tests/operator-recovery.browser.js`：延迟上传切换委托不串单；真实创作页预填；参考图阶段刷新沿用同一任务；只提交一次参考图，不自动三维；结果返回；经营备份到干净浏览器恢复。云端生成使用替身。
- `tests/operator-adversarial.browser.js`：双页签作品选择归属、延迟分享后导出归属、取消分享不记录导出、旧需求结果保留正确的来源事实。

- Impeccable机械检测最终输出 `[]`；桌面和手机截图已检查，原生备份文件输入的误显示与文字对比度已修正。

## 独立审查及修复

审查复现了延迟上传、共享作品选择返回键、异步导出读取全局委托造成的串单，以及取消分享仍算导出。均改为发起时的编号/版本，作品选择上下文放在本页路由，取消不记导出；专项浏览器检查通过。

参考图保存和恢复的单独分支补齐经营者上下文；旧版本结果以其实际输入照片和地点保存，不套用当前新版需求。已有记录通过原创作页恢复，未完成的任务编号可以继续领取。

没有自动提交、推送或部署。原4181本机服务已重载，服务端密钥沿用原环境文件。
