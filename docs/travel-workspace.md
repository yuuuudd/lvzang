# 旅藏：旅行对话与方案工作台

入口：http://localhost:4180/travel.html。运行方式保持 `npm start`；当前演示服务使用 PORT=4180。

左侧持续对话，右侧可平移/缩放的方案画布。节点标题支持拖动、方向键移动；画布背景可拖动，Ctrl+滚轮缩放，工具栏可适应和重置布局。移动端自动堆叠为可读卡片。

广州珠江两岸是默认示例：广东省博物馆、花城广场、广州塔。导览画面是固定的生成素材，地标标签和行程路线为交互图层。示意图不用于精确道路导航；地点卡保留实际导航入口。苏州和杭州仍可策划，使用相对地点示意，不复用广州插画。

用户可以直接描述需求，也可在“导入攻略”中粘贴正文或读取截图。目的地、时长、策划模式位于“策划选项”。已有 AI 配置时默认选 AI，但打开页面不会自动提交请求。本地模式明确显示规则示范。

对话通过 `/api/travel-chat/stream`。DeepSeek 接收最近12条对话与当前方案，先直接理解和回答本轮问题；问答保留当前方案，不触发行程重排。需要策划或修改时，Agent 提取城市与约束，整合攻略、组织路线并校验。返回阶段开始、完成和校验后的条件。时间、预算、偏好先显示待确认修改，旧行程保留；完整方案通过校验后更新行程与地图。聊天中保留要求、回复和最近调整。失败/停止会还原条件，不覆盖上一份已保存方案；关闭流会取消上游模型请求。

预算是规划上限，尚未核价；预约、开放和具体交通仍待确认。收藏、分享、STL、模拟签到、商家活动与供应商报价记录继续可用。广州新增小蛮腰、岭南宝盒等简化预制模型。记录仍在本机，不包含真实支付、工厂履约或到访核验。
