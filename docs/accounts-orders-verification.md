# 统一登录与用户/经营者订单同步

2026-10-06。实际入口 `http://localhost:4181/portal.html`，本机服务已重载。

## 首次使用

1. 在同一登录页面选择“创建工作室”，自行设置账号/密码。仅首次本机初始化可创建工作室账号，它拥有用户与经营者角色。
2. 普通体验者选择“注册用户”；普通注册不授予经营者权限。
3. 工作室账号在顶栏切换角色；也可以在另一个浏览器登录普通用户账号演示双端。
4. 用户从合集/单件的“申请定制”进入已预填的表单，或从“我的订单”新建，提交照片和要求。
5. 经营者默认查看“用户提交”，收到需求后接受或退回补充。已提交的参考图/模型可直接采用，不重复生图建模。
6. 新照片通过原单件创作页生成，参考图和三维保存后关联服务端同一订单；审核通过后用户可查看、下载、确认或要求修改。
7. 用户确认当前作品、经营者导出当前交付版本后，可记录实际交付。手动代录保留为次渠道。

## 数据与权限

- 账号、哈希密码、会话、订单和任务归属写入 `output/accounts/workspace.json`；提交/制作文件在 `output/accounts/files/`。这些路径被Git忽略，不公开静态访问。
- 密码使用原生scrypt加盐；Cookie为HttpOnly/SameSite，会话仅存随机令牌的哈希，默认七天。角色与订单/file所有权在服务端检查。
- 用户只看自己的订单和公开制作结果；内部备注、费用和创作任务快照不返回用户。素材通过鉴权API读取。
- 订单按版本写入，旧版本保存被拒绝；审核、客户确认、结果文件和交付版本一致才允许交付。交付后可以补充经营记录。
- 每次结果有独立服务端作品编号，同一模型在多份委托使用不会混淆归属。
- 个人旅行收藏和历史按账号隔离；首次工作室账号迁移原本机资料，同页/跨标签页以浏览器原生锁协调。旧本机任务仅工作室所有者可恢复归属。
- 本机资料备份与服务端订单分开；共享订单不依赖用户和经营者共用IndexedDB。另一个浏览器登录可直接读取服务端订单。
- 空闲时约五秒检查状态变化；有未保存输入时不自动覆盖。稳定状态不反复重建经营者模型预览。

## 实施范围

保留现有原生Web和Node应用，未安装外部账号/数据库依赖。当前持久文件由一个Node进程负责，适用于本机演示/小规模试点；多进程或serverless部署需改用共享数据库/持久存储。

同一服务上的不同浏览器已验证。当前监听本机地址，真正从手机或其他电脑访问还需要部署到可访问地址；本轮没有发布公网、支付、物流或自动商家履约。

已有图片/模型与照片上传至本订单，不把整个个人收藏自动上传。长需求完整保留在服务端；本机回忆和创作工具按各自既有长度限制保存摘要，界面可展开完整需求。
