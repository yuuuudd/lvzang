# 旅藏页面与跳转

主导航只有两个业务区：**去旅行**和**留回忆**。旅藏标志返回首页；首页提供产品介绍及回忆模板体验。

| 入口 | 去向 | 下一步 |
| --- | --- | --- |
| 去旅行 | /travel.html | 策划路线、查看地点；旅行结束后添加回忆 |
| 添加回忆 | /collection.html#world/create | 带入旅行标题、地点及日期，添加照片与故事 |
| 留回忆 | /collection.html#world/canvas | 回忆画布 → 旅行详情 → 照片或作品 |
| 模板体验 | /#templates | 生成后打开对应回忆详情 |
| 定制我的 / 定制这段回忆 | /orders.html#new（具体作品带 work 或 trip） | 确认素材与需求 → 提交 → 查看订单 |
| 我的定制订单 | /orders.html | 订单详情、确认作品；返回留回忆 |
| 身份菜单 → 经营者 | /operator.html | 接收需求 → 确认需求 → 制作 → 审核 → 交付 |
| 经营者制作 | /production.html?operator=委托ID | 旅藏委托制作页，结果关联原委托；返回该委托 |

清理的旧入口：旅行页中的第二套展柜、商家工作台入口、主题活动跨页入口；首页页脚、旅行页页脚和纪念品弹窗的拾光入口；经营者跳转旧拾光制作页。旧 #merchant/#collection 书签分别转入经营者工作台及回忆画布。已分享的 #exhibition 链接继续只读展示；旧本机记录保留，收藏仍可导入回忆画布。

/index.html、/simple.html 属于独立旧应用，旅藏业务入口不再链接它们。委托制作复用已有生成引擎，但使用独立页面、委托范围的制作记录及返回路径，不加载旧应用的旅行合集和版本切换。
