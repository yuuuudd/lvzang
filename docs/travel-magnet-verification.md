# 收藏柜与冰箱贴墙：实现与验证

日期：2026-10-05。

## 实际入口

- `/collection.html#collection/map`：个人地图冰箱贴墙。
- `/collection.html#collection/cabinet`：同一收藏的柜子视图。
- `/collection.html?demo=1#collection/map`：主动打开明确标注的虚构示例，不写入正式收藏。
- 原 `/travel.html` 顶部“旅行收藏”接入新入口；原旅行、旧展柜与商家功能保留。

## 已实现

两套概念图分别落为地图墙与微缩柜子页面；3D详情、回忆册、照片编辑、创作表单、实体定制、备份与需求使用不同页面状态或弹窗。收藏中可同时有个人/共同记忆、浮雕冰箱贴/微缩摆件；同城不同旅行独立保存。

图案正视素材与微缩外观素材依据批准概念图用内置ImageGen新生成，没有使用整张界面截图作页面背景。冰箱贴交互使用独立分层高度场、纹理、真实侧面和平背；微缩交互使用可旋转的建筑、底座与树木网格。收藏缩略图及摆放情境是美术效果素材，**不等于实际导出网格的照片**。微缩交互几何是风格化样件，精细度低于美术效果图，不声称生产级复原。

作品、照片、回忆与本机需求存IndexedDB。支持导出STL、分享卡、含压缩照片的完整ZIP、恢复备份。照片与作者示例均为虚构。无付款、发货、跨设备邀请或远程商家收单；刻字只记录需求，尚未加入几何。冰箱贴平背用于后续粘贴磁铁，不虚构已经安装的磁吸结构。
