# 旅藏高德地图配置

高德地图接入用于显示真实 3D 底图、查询景点坐标，并按当前选中的旅行日期查询步行或驾车路线。用户也可点击地标选择起点与终点，单独比较两地的路程。旅行需求档案和已保存行程仍独立保留。

本机已使用你提供的 Web端（JS API）凭据完成配置，可以直接打开[旅藏工作台](http://localhost:4180/travel.html)。

## 申请凭据

1. 打开[高德开放平台控制台](https://console.amap.com/dev/key/app)，登录自己的账号。按页面要求完成开发者注册或实名认证。
2. 进入“应用管理 → 我的应用”，创建一个应用，例如“旅藏比赛项目”。
3. 在该应用下添加 Key，服务平台选择 **Web端（JS API）**。
4. 保存该 Key 及对应的安全密钥 **securityJsCode**。这两个值必须属于同一个 JS API Key。

步骤和服务类型以[高德官方准备说明](https://lbs.amap.com/api/javascript-api-v2/prerequisites)为准。账号登录、身份认证和账号协议由账号本人完成。

## 本地配置

在项目根目录已经存在的 `.env` 中增加这两项，保留已有 DeepSeek 配置：

```dotenv
AMAP_JS_API_KEY=申请到的Web端JS_API_Key
AMAP_SECURITY_JS_CODE=该Key对应的securityJsCode
```

`.env.example` 只包含空字段说明，真实值保留在已忽略的 `.env`。配置后重启本地服务，并刷新[旅藏工作台](http://localhost:4180/travel.html)。

```powershell
Set-Location -LiteralPath 'C:\Users\z1z1h1\Documents\Codex\2026-10-05\https-github-com-yuuuudd-lvzang-https\work\lvzang'

```

JS API 的公共 Key 用于浏览器加载官方 SDK；安全密钥由本地 Node 服务通过 `/_AMapService` 代理添加。浏览器配置接口不返回安全密钥。这符合[高德官方的服务代理方式](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。

## 地图如何确定位置

景点名称先在目的地城市内通过高德 POI 搜索查询。名称明确且结果唯一时使用高德坐标；重名或模糊结果展示地址供确认。没有查到的地点保持“待确认”，不会用旧示意图坐标或模型推测坐标填补。

地图显示整趟已接受行程中已通过高德确认位置的地标，并突出当前选中日期的地点；独立探索层默认开启，显示符合排除条件和名称/别名去重规则的广州探索地点，明确标注“探索 · 未入行程”。探索地点不带行程日期、时间或费用，可参与独立路程比较。自动日行程路线只使用当天已接受的地点。步行或驾车线路采用高德返回的路段几何形状，显示其距离和时间估算。查询失败时保留明确的失败状态，不用景点间的直线替代交通路线。地图显示的交通时间不会自动改写已保存的旅行安排。

旧广州插画导览保留为明确标注的可选示意视图。没有配置凭据时，默认真实地图显示待配置状态。

地点和路线协议分别参见[POI 搜索](https://lbs.amap.com/api/javascript-api-v2/guide/services/autocomplete)、[路线规划](https://lbs.amap.com/api/javascript-api-v2/guide/services/navigation)。外部高德链接在地点确认后使用坐标；未确认时只是名称搜索入口。[坐标标注协议](https://lbs.amap.com/api/uri-api/gettingstarted)、[路线链接协议](https://lbs.amap.com/api/uri-api/guide/travel/route)

## 立体地标与两地比较

真实地图默认以 45° 立体视角显示高德原生建筑，已接受地点和独立探索地点叠加可点击的微缩建筑。广州池包含广东省博物馆、花城广场、广州塔、广州大剧院、广州图书馆、广州西塔（IFC）、广州东塔（CTF）和第二少年宫八处；具体显示数量取决于已接受地点、探索开关、去重和排除条件。造型用于识别景点，是风格化表达，不是建筑测绘模型；真实位置、道路与交通数据仍来自高德。三角几何由静态 Canvas 渲染，不为每个地标新建 WebGL 上下文或持续渲染。按钮的 ARIA 描述保留完整名称和状态，装饰 Canvas 对辅助技术隐藏。

微缩地标与标签密集时可在屏幕上稍作避让，但不会移动高德 POI 坐标。虚线引线和地图圆点指向真实位置，路线仍使用真实坐标查询。既有栅格资产保持不变。

地图支持高德原生拖动、滚轮、多点触摸和键盘交互，以及自定义 ± 缩放控件；工作台手势不接管地图，迟到 POI 的自动适配不会覆盖用户的移动或缩放意图。PlaceSearch 起始查询按 400ms 间隔排队，避免实际八处同时请求造成 QPS 限流。

先点击一个已定位地标选起点，地图保留已接受及探索地标的可选视野，再点击另一个选终点；之后点击其他地标会替换终点。也可使用明确的起点、终点按钮，或交换、清空两端。步行与驾车切换保留端点，并查询对应交通方式。查询失败可重试，过期查询不会覆盖新的选择。探索显示和比较结果独立于当天自动路线，不会写回需求档案或增删、重排已保存行程。

已有本地高德配置可继续使用，无需为这一扩展申请新的 Key。安全密钥仍由本地服务代理添加；插画示意视图保留。局部设计和状态约束见 [地图扩展说明](travel-map-explorer.surface.md)。

## 配置后的验收

- 打开真实地图，能看到高德底图及其标识。
- 查看当天景点名称和地址，确认与目的地相符。
- 切换旅行日期，当天高亮和自动路线更新；整趟行程中已定位的地标仍可查看。
- 探索层默认开启，显示符合去重与排除规则的地点；其“探索 · 未入行程”标签可读，开关不修改保存方案。
- 地图拖动、滚轮、自定义 ± 和其他原生交互不改变工作台位置或缩放；迟到 POI 不重置用户视野。
- 至少两站的一天可查询步行或驾车路线，并显示高德交通估算。
- 地标可通过鼠标或键盘选择；先选起点、后选终点，后续选择替换终点。
- 交换、清空、切换步行或驾车后，端点和比较结果与当前选择一致。
- 比较两地路程后，原旅行需求与已保存行程保持一致。
- 一天只有一站时仍显示该站及其他已接受/可探索地点；自动日行程路线不连接探索地点，空行程和待定位状态有明确说明。
- 修改预算或刷新页面后，旅行需求和路线不丢失。

代码与模拟服务测试可以在没有 Key 的情况下完成；真实高德服务是否可用，需要配置上述凭据后另行验证。
