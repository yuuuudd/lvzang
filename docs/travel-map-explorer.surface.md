# 旅藏地图扩展：立体地标与路程比较

日期：2026-10-07。范围：`/travel.html` 的地图节点。模式：Operate。

本文件是 [DESIGN.md](../DESIGN.md) 所述旅藏工作台的组件扩展说明，沿用已有浅灰/近白背景、炭黑文字、黄绿色主操作、中文无衬线字体和控件形状；不替换全局设计系统。既有城市插画仍适用于明确标注的可选示意视图，真实地图的数据与精度边界以本文件和 [高德地图配置](amap-setup.md) 为准。

## 任务与内容

游客在当前行程的真实地图上认出景点，选择起点和终点，比较步行或驾车的路程，再继续原有规划。地图是工作台最大节点，地标是选择入口，地图下方的比较面板承接端点、交通方式和结果。

地图显示整趟已接受行程中位置已确认的地标，突出当天景点；自动日行程路线仅连接当天已接受的地点。独立探索层默认开启，广州池包含广东省博物馆、花城广场、广州塔、广州大剧院、广州图书馆、广州西塔（IFC）、广州东塔（CTF）和第二少年宫共八处。探索候选去除已接受地点，按名称/别名去重并遵守用户排除条件；可参与两地比较，但始终标注“探索 · 未入行程”，不虚构行程日期、时间、费用或坐标。未定位或有重名歧义的地点继续等待确认，不能填入猜测坐标。

## 局部方向

THESIS：可识别的微缩地标把真实位置变成可直接选择的旅行目的地。

OWN-WORLD：继承旅藏浅色工作台和黄绿色操作，建筑轮廓负责识别，清楚的文字负责地点、日期与端点状态。

STORY：认出建筑，先选起点、再选终点，读取高德路程估算，继续原有行程。

FIRST VIEWPORT：地图节点容纳立体城市、醒目的微缩建筑和紧凑的视图控制；两地比较直接接在地图下方，不改变聊天与画布的主次。

FORM：现有 Operate 界面的地图组件扩展。

## 组件与状态

| 组件 | 已实现行为与约束 |
| --- | --- |
| 真实地图 | 默认使用高德 JS API 2.0 的 3D 视角与原生建筑，初始俯仰角 45°；地图署名保留。 |
| 微缩地标 | 三角几何经静态 Canvas 2D 渲染为立体造型，作为可点击 DOM 标记锚定到已确认 POI。广州八种建筑有不同轮廓；造型是风格化表达，不能称为测绘复原。 |
| 位置与避让 | POI 坐标保持不变；邻近微缩地标与标签使用有限的屏幕像素偏移避免碰撞，SVG 虚线引线和圆点指示原始真实位置。 |
| 地标标签 | 可读地点名、行程日期/站点信息或“探索 · 未入行程”；当天、起点、终点与聚焦状态可辨识。选择入口是原生按钮，ARIA 描述保留完整名称及状态，装饰 Canvas 对辅助技术隐藏。 |
| 探索层 | 默认开启，可独立显示/隐藏；不写回旅行需求或已保存行程，不改变已接受地点的日期、费用和排序。 |
| 地图交互 | 高德原生拖动、滚轮、多点触摸和键盘交互与自定义 ± 缩放归地图所有，工作台不接管这些手势。用户的移动/缩放意图不会被迟到 POI 的自动适配覆盖。 |
| 地点查询 | PlaceSearch 起始查询按 400ms 间隔排队，避免八处同时查询造成实际 QPS 限流；过期结果不能恢复旧方案或覆盖用户视野。 |
| 地点检查 | 展示当前关注地点，提供明确设置起点或终点的操作；位置未确认时先处理定位。 |
| 两地比较 | 首次点击设起点并保留整趟行程的可选地标视野，第二个不同地标设终点，后续点击替换终点；重复点起点保留起点。显式设置起点会重新开始选择。完整端点可交换，清空移除比较。 |
| 交通方式 | 切换步行/驾车保留端点，查询对应路段；显示高德几何路线、距离与时间估算。 |
| 失败与等待 | 展示真实查询状态和重试入口；迟到回调与过期结果不能覆盖新选择，失败不能绘制直线并称为道路路线。 |
| 示意视图 | 原城市插画保留并明确标注示意，不能承诺道路导航精度。 |

探索显示、比较选择和结果不修改已接受的需求档案，也不增加、删除或重排已保存行程。当天自动路线与用户选择的比较路线分别表达各自的用途；探索地标只参加独立比较。切换日期、方案或地图视图后，过期查询不能恢复旧结果。

地图手势与工作台画布手势分开处理，建筑按钮和比较操作保留可见焦点；移动端使用可读的控件与堆叠面板。减少动态效果时，建筑和状态信息仍可读取。静态微缩建筑无需每个标记各建 WebGL 上下文，也无需连续渲染循环。既有交付栅格资产保持不变。
