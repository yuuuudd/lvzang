# 自动旋转与逐张照片故事验收

日期：2026-10-06。

- 合集打开后，各个真实模型自动旋转；轻点模型进入故事详情，拖动超过7px继续旋转且不跳转。键盘 Enter / Space 也能进入详情。系统减少动态效果设置被保留。
- 作品详情与照片详情提供旋转、放大、缩小、复位和GLB下载。右栏由310px增至350px，中等屏幕为320px，手机保持纵向布局。
- 每张照片独立保存标题和故事，可编辑，纳入完整备份。旧拾光合集会补回原故事及能够确定的模型关联。后台资产导入不能覆盖最新人工文字，人工清空的故事也不会被旧文字替代。
- 照片只显示与其来源编号匹配的模型。没有模型时显示原照片与故事，提供单张生成入口，生成结果归入原合集，不另生成封面。提交前保存照片与任务编号的关联，恢复页面沿用同一任务。
- 待制作合集可备份原照片和故事；它无需尚未生成的模型文件。

验证结果：

- `npm test`：206项通过，0失败。
- `node tests/photo-story.browser.js`：默认旋转、轻点/拖动、逐张故事、对应模型下载、人工编辑与清空、旧拾光迁移、后台写入保护、待制作备份、手机布局通过。
- `node tests/travel-gallery.browser.js`：主画布/合集/详情、独立模型、合集图、单张补生成并入原合集、提交前持久化任务编号、备份及手机布局通过；全部外部生成接口使用模拟服务。
- `node scripts/verify-gallery-live.mjs`：本地保存的3个真实GLB与4张照片故事通过，桌面和手机无页面错误；只查询与下载已有文件，未提交模型或封面生成。
