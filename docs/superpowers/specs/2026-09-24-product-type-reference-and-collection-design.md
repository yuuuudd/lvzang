# 纪念品品类分流与赛博文创收藏：设计规格

## 目标与边界

游客从旅行画的一个记忆点，或从单件照片与故事，先选纪念品品类，再生成符合该品类形态的参考图。同一记忆可以制作多个品类版本，作品即使不出售也能进入个人赛博文创收藏。视觉风格仍可独立选择，不代替品类。

本次覆盖四个品类：亚克力钥匙扣、平面冰箱贴、立体冰箱贴、桌面小手办。销售、下单、厂商对接、账号和跨设备同步不属于本次范围。平面作品的首版输出是可保存的概念图，不宣称已含厂家可直接生产的刀线或白墨层；立体作品的几何检查也不等于试打通过。

## 方案取舍

采用“品类先于构思”的路线，让同一份记忆素材生成不同参考图。只在导出时切换品类会让钥匙扣沿用磁贴的厚实体构图、手办沿用平背造型，不能满足目标。为每个品类另建一套应用和收藏库会重复照片、故事与旅行关联；首版沿用现有生成和历史链路，在需要跨设备展示时再拆出独立收藏服务。

## 选择时机与用户流程

1. 旅行画和记忆点的生成方式保持现状。点击一个记忆点的“制作成纪念品”，先选择四类之一。独立单件创作也提供同一品类选择，默认沿用现有“立体冰箱贴”，保证旧入口行为不突变。
2. 品类与风格、照片、故事、地点一起进入构思请求。构思、最终生图提示词和参考图回看使用同一个品类值；页面在提交付费生图前展示所选品类。
3. 平面类生成正面概念图，确认后即可作为数字作品收藏和下载图片，不自动提交三维任务。立体类先保存参考图；半自动时用户确认再建模，全自动时按现有流程继续建模。
4. 修改参考图保持原品类。要换品类，作为同一记忆的新版本重新构思和生图，不把已有冰箱贴图直接改名为手办。
5. 收藏页按旅行／独立作品、记忆点和品类展示所有版本；同一记忆下的多个品类都能打开。参考图和模型分别标明阶段，不以“最新三维作品”覆盖其他版本。

## 品类规则

| 品类 ID | 构图与参考图要求 | 后续处理 |
| --- | --- | --- |
| `acrylic_keychain` | 单个完整平面主体，正面、清晰外轮廓，主体上方留挂孔空间；不画成实物拍摄图 | 保存概念图；厂家规格确定后才制作刀线与挂孔文件 |
| `flat_magnet` | 单个完整平面主体，正面、清晰外轮廓，不留挂孔；不画立体底座 | 保存概念图；厂家规格确定后才制作裁切文件 |
| `sculpted_magnet` | 紧凑、有厚度、背面适合贴磁铁的立体主体；沿用现有磁贴参考图与三维路线 | 沿用现有几何检查及 STL／3MF 导出，仍需切片和试打 |
| `figurine` | 独立站立的完整立体主体，必要时有底座；不可出现磁贴平背、挂孔或贴片轮廓 | 从参考图生成三维；保存数字模型，打印导出须通过适用于手办的几何检查 |

人物半身照不自动补造照片中不可见的腿脚；手办可使用半身像加底座。所有品类都保留照片和故事中有依据的人、物与地点，不把类型约束当作杜撰素材的许可。三维建模仍依据一张参考图，无法保证背面与真实人物或建筑完全一致，回看需明确提示。

## 数据与实现边界

给新作品记录和生成任务增加受服务端校验的 `productType`。旧记录缺少该字段时保持旧展示；已知 `tripo3d` 历史可显示为立体冰箱贴，旧浮雕不强行归入四类。沿用 IndexedDB 的 `artworks` 与 `trips`、现有 `tripId`／`memoryId` 关联及单件导出能力，先把收藏页作为现有站点的视图；如果以后需要跨设备或公开收藏，再单独设计仓库服务或仓库项目。

目前 `server.js` 的构思系统词和 `tripo.js` 的最终生图词都固定描述磁贴；两层必须按 `productType` 分流，且 `/api/artwork` 与 `/api/design` 都拒绝未知品类。现有 `sculpture` 布尔值仅代表旧的平面／立体路径，不能再作为品类来源。参考图回看按品类检查轮廓、挂孔空间、平背或站立底座；不能沿用统一的“冰箱贴回看员”。

`figurine` 不经过现有 `buildMagnetModel` 中的磁贴比例和平背限制。其检查至少区分封闭性、连通性、悬空及底部支撑；未通过时可以收藏数字模型，但不得标注为可打印或开放打印导出。首版不自动修复任意 AI 网格，不承诺手办能直接量产。

## 失败与保存

生图、回看或建模失败时保留已经成功保存的前一阶段和品类选择，允许继续取结果或定向修改，避免无意重复提交付费任务。浏览器存储失败应明确告知并提供当前图片或模型的单件下载。收藏仍存于当前浏览器，清除站点数据会丢失；页面需说明这一限制。

## 验收

- 同一张来源照片和故事分别选择四类时，构思与实际提交的生图提示词包含不同的品类形态约束；不能全部落到冰箱贴提示词。
- 平面钥匙扣和平面冰箱贴保存概念图后不提交三维建模，能在收藏中分别打开；钥匙扣留挂孔空间，平面冰箱贴不带挂孔。
- 立体冰箱贴沿用原有可导出的成功路径；小手办参考图不出现磁贴平背，并能生成、保存和旋转查看数字三维。其打印状态只由手办检查决定。
- 同一记忆点保存多个品类后，收藏同时显示所有版本；刷新后仍能打开。旧历史仍可打开。
- 未知品类在服务端被拒绝；付费任务失败时已保存的参考图不丢失。无 API 额度的自动检查使用模拟响应，不消耗真实生成额度。
