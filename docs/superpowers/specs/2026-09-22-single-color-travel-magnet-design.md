# 单色文旅浮雕冰箱贴：软件端设计

## 2026-09-22 实现修订

用户确认拥有 DeepSeek 开放平台 API Key。首版现在包含真实服务端 DeepSeek 视觉与 JSON 设计接口，默认 `deepseek-flash`；点击生成才发送故事与压缩照片，并明确提示。保留主动选择的离线规则模式，错误不会静默降级。受约束设计可调整构图、人数、缩放、装饰、短句与照片转换参数；不承诺生成式图像重绘。

实际实现有旅行、亲情、朋友、爱情四类主题，地点文字可改，默认骑楼插画不随地点自动变成新地标。文件位于 `public/`，原生 Node 服务只公开白名单静态资源。参数和照片变化后重新生成共享网格；预览用 WebGL，导出二进制 STL。照片提供人物 / 风景、取景、阈值、反相、块面 / 轮廓。语音达到 300 字时明确提示并停止录音；新故事或提交时冻结已确认文本，丢弃尚未确认的语音片段。

真实 API 连接已验证：文字、测试照片、修改指令及浏览器生成均成功。人工验证仍需完成：现场相机和语音、Bambu Studio 切片与白色实物试打。以下为原始设计依据；实现与验证进度以 `docs/implementation-progress.md` 和 README 为准。

## 目标

在黑客松现场演示一条可重复运行的链路：游客通过语音或打字讲述旅行故事，可现场拍照或选择已有照片，系统生成受控的个性化浮雕设计，展示接近实物的预览，并导出可由 Bambu Studio 切片的 STL 文件。

## 当前约束

- 剩余开发时间约 40 小时。
- 打印设备为拓竹 A1，当前只有白色耗材，按默认 0.4 mm 喷嘴设计。
- 磁铁次日采购；首版只在背面保留平整粘贴面，不生成磁铁孔。
- 首版只支持一个景点、一种冰箱贴外形、三类故事主题。
- 打字、规则设计和 STL 导出必须在没有模型 API 密钥时可演示；语音转写的支持情况和联网要求须在参赛设备上验证，不能承诺全部功能离线可用。
- 用户已明确要求人物和风景照片均支持，入口包含现场拍照和选择已有图片。首版建议共用图案简化和浅浮雕管线，分别提供人物与风景构图；该表现形式属于此次更新提出的设计。

## 用户流程

1. 游客点击“讲述我的故事”开始语音输入，再次点击停止；也可直接在始终可见的文本框中打字。
2. 语音转写显示为可编辑文字，游客确认或修正人名、地名和日期。故事长度限制调整为 300 个字符，超限提示编辑，不静默截断。
3. 游客可点击“拍张照片”或“选择照片”；图片展示缩略预览，并提供替换和删除。没有照片也可以继续。
   添加照片后，游客选择人物或风景构图，裁剪主体，并确认简化图案预览。类型由游客选择，不依赖未经验证的自动分类。
4. 游客确认故事和照片后，主动点击“生成我的纪念品”。系统识别主题，生成一句不超过 8 个汉字的短文案，并选择对应装饰元素。
5. 游客在同一页查看白色浮雕预览，可修改短文案或切换主题。
6. 游客点击导出，浏览器生成 STL 文件。
7. 工作人员把 STL 导入 Bambu Studio，使用预先验证的 A1 切片参数打印。

## 语音与照片入口

- 语音首轮采用浏览器能力检测；不支持、拒绝权限、无声或网络识别失败时，解释原因并保留手动输入内容。规则模式明确标识为演示模式，不能称作已经接入 AI。
- 语音只在用户主动操作后开始；停止、切换输入或离开页面时结束识别，不覆盖已经确认的文字。
- 桌面端可用摄像头时提供画面预览、拍照和重拍；移动端兼容设备拍照入口，并始终保留普通图片选择入口。
- 相机仅在用户点击后请求权限，拍摄完成或关闭相机时释放摄像头。开发使用 localhost，其他设备访问或部署使用 HTTPS。
- 首版图片接受可实际解码的 JPEG、PNG 和 WebP，最大 10 MB；不支持的格式、损坏文件和超过 24 百万像素的图片给出明确提示。处理前缩小到最长边 1600 像素。
- 照片入口默认只在浏览器本地处理，不自动保存原图；若后续接入远程图像服务，在生成操作处说明会发送照片。
- 照片是否已用于成品必须如实显示，不能把仅显示缩略图当成照片已转换为浮雕。

## 照片到成品的首版方案

人物和风景使用同一套图案管线：手动裁剪、缩小、灰度处理、对比度和阈值调节、简化成粗线或色块，再加入统一高度图。用户可以在原图、简化图案和实际模型预览之间比较。此方案生成照片图案的浅浮雕，不声称恢复真实人脸、建筑或景物的三维深度；阈值处理也不标为 AI 抠图。

- 人物构图：照片主体占中心大面积，地点、日期和短句排列在下方，地标只作简化边饰。合照允许裁剪，但不承诺自动区分或保留每张小脸的细节。
- 风景构图：照片作为主要图案，替换默认地标插画，下方保留地点、日期和短句。
- 没有照片：使用已有地标和故事主题元素生成模型。
- 简化结果不可辨认时让游客调整裁剪和阈值，或主动选择使用默认地标；不能静默丢弃照片继续生成。
- 将照片转成明确的浮雕掩膜后再生成高度：背景为底板，图案为凸起。不能把完全不透明照片的 alpha 通道直接当作浮雕掩膜，也不能把图像亮度称为真实几何深度。
- 细线简化和可读性需要在白色耗材、A1 默认喷嘴上试打确认；人物相似度不作为尚未验证的承诺。

## 设计边界

生成结果由固定地标、主题装饰、短文案和日期组成。故事理解只输出受限参数，不允许模型直接生成任意三维几何。这使每次输出都能通过同一套尺寸和制造规则。

首版提供本地规则生成器，保证断网和无密钥时可用。后续可在相同输入输出接口后接入模型 API；这不属于第一轮实现。

## 模型生成

浏览器把构图绘制为灰度高度图，再转换为封闭的矩形高度场网格。底板尺寸默认 60 × 45 × 2 mm，浮雕高度默认 1.2 mm。STL 与页面预览使用同一份高度图，避免预览和实物不一致。

导出前校验短文案非空、长度不超过 8 个汉字、日期格式合法。输入为空时使用可演示的默认故事和文案。

## 页面

单页分为故事输入区、可选照片区、结果预览区和制作信息区。语音是醒目的故事入口，打字输入始终可见。主流程依次为讲述、可选照片、确认生成和导出。界面突出旅行故事和成品，不出现网格等内部实现术语。

## 失败处理

- 无法识别主题时使用“旅行”通用主题。
- 文案过长时提示游客缩短，不静默截断。
- STL 生成失败时保留当前设计并显示可重试提示。
- 浏览器不支持必要能力时显示明确提示。
- 麦克风或相机权限拒绝时，分别可继续打字或选择图片，不阻断创作。

## 验收

- 三段代表亲情、友情、爱情的故事能生成不同元素和文案。
- 修改文案后，预览和导出模型同时变化。
- 导出的 STL 是非空、封闭的二进制网格，并可导入 Bambu Studio。
- 页面刷新后无 API 密钥也能重新完成打字、规则设计和 STL 导出；语音须单独记录参赛设备上的测试结果。
- 停止录音后可以修正转写，已有文字在重试、失败及切换输入时不丢失。
- 拍照和图片选择进入同一张可替换、可删除的图片预览，拒绝权限后仍可继续。
- 各用一张人物照片和风景照片跑通裁剪、简化、模型预览、STL 导出；更换照片必须改变模型几何，不能只改变页面缩略图。
- 移除照片后恢复默认地标构图；用户输入的故事和确认文案保留。
- 电脑端与手机宽度下均能完成主流程。

## 明确不做

真实支付、账号、数据库、多门店、打印机远程控制、多色打印、任意三维模型生成和磁铁槽自动适配。照片首版限单色图案浅浮雕，不包含照片恢复完整三维人像或场景。
