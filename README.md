# 拾光 · 可交互的旅行回忆画与立体纪念物

新增 **旅藏文旅体验**：打开 `/travel.html`，从可选攻略与个人需求出发，规划路线、解锁可旋转的 3D 纪念品、分享旅行展柜，并在本机商家工作台管理主题活动与定制报价。真实多 Agent 协作使用现有 DeepSeek 配置；本地示范不调用 AI。完整链路、比赛演示与边界见 [旅藏演示说明](docs/travel-demo.md)。原有创作入口保留。

填写旅行故事并选择 2–9 张照片后，点击一次“生成旅行回忆画”：Agent 为每张照片挑选有画面依据的人、物或场景，本机 SAM 抠出元素，Tripo GPT Image 2.5 生成完整横幅插画，DeepSeek 对照导图定位画中元素，本机 SAM 自动生成并复核点击区域。点击画中元素可查看原照片、这一刻的故事与纪念物；定位不准时仍可手动修正。原有单件创作入口和历史作品保留。

照片、故事、元素导图与生成画保存在当前浏览器的 IndexedDB；旧拼贴合集可打开并主动转换。照片会发送给 DeepSeek 策展，元素导图会发送给 Tripo 生图，生成画会交给 DeepSeek 定位；抠图在本机完成，首次使用需下载模型文件到 `.superpowers/model-cache`。一次点击会提交一次付费 Image 生图任务；定位不确定时自动复核一次，不重复生图。立体制作仍由用户从画中记忆点单独触发。扫码分享、AR 和跨设备同步不在这一版；三维导出后仍需切片与试打。

## 这一刻的立体创作

这一刻的来源照片必选，故事选填。从旅行合集进入时，带入所选记忆点的照片和故事；整趟旅行的故事仍留在合集。主题预设和插画风格可以选择，地点与日期直接显示且可留空。Agent 根据照片、这一刻的故事和主题确定单一构图，再提交付费生图。实际参考图返回后，视觉回看对照来源照片、故事、场景和活动元素；建议可填入修改框，是否重绘由用户决定。旧记录仍可打开。

页面的四步创作记录和作品诞生卡标明本轮进展。生成历史默认收起，展开后可打开、刷新或删除作品。
单件创作可选“半自动”或“全自动”：半自动在参考图和自动回看完成后暂停，可修改参考图并由用户决定是否提交建模；全自动在回看成功后继续提交 3D 建模和本地几何检查。自动回看失败时保留参考图，等待人工核对，不额外提交建模。默认使用半自动。

本地开发测试可在 `.env` 设置 `DEVELOPER_BATCH_3D=true` 并重启服务。合集画的每张照片恰好有一个已定位记忆点时，页面显示“开发测试 · 批量生成 3D”：点击后最多并行处理两件未完成资产，从参考图到 3D 各自推进。每件使用该记忆点自己的照片和故事；已完成的立体作品会跳过，已保存的任务编号用于继续领取结果，避免重复提交付费任务。这个折叠入口只用于本地测试，普通用户仍从合集画选择想制作的单件。批量结果保存在当前浏览器的生成历史中；服务重启后未完成的单件任务仍可能无法领取，需在 Tripo 核对任务编号。

## 新版立体制作

- 数字参考图和三维回忆录保留照片中人物、衣着、物件与场景的主要颜色；Tripo 建模始终开启纹理和 UV。打印耗材默认白色，最多四色；导出 3MF 时将 GLB 内嵌纹理、顶点色或材质色量化至固定米白/砖红/深蓝/灰绿调色板。Bambu 3MF 携带涂色和耗材颜色，不是可拆装分色零件；仍需在 Bambu Studio 核对槽位、切片换色次数和成本。STL 不保存颜色。旧白模缺失的源颜色无法靠更改色数找回，必须重新建模；不会套用参考图的平面投影假装三维配色。
- 默认故事创作暂不加工磁铁孔。旧版结构试验仍保留带孔样本，供后续单独验证。
- “结构实验 · AI 拱廊模板”（非默认创作）：DeepSeek 理解输入并选择可控拱廊模板的参数，根据实际几何报告决定接受、简化、加粗或停止。最多自动修正一次，并保存修正前后模型、报告、决策理由。当前模板不是任意地标精确复原，短句作为作品标题保存，照片不用于恢复人物面孔。
- “故事创作”（默认）：必须上传这一刻的照片，故事、地点和日期可留空，人物或风景主体由照片与故事自动判断。可选珐琅插画、奶油黏土、复古拼贴、陶瓷釉彩或木雕；参考图不加文字或名牌，保留素材主要原色。打印仍受单色／最多四色和实体连接约束。启动时读取 `prompts/memory-design.md`。主题预设默认“无预设”，不会自动套入固定地点或活动角色。选“深圳啤酒小镇 · 黑客松与塔奇克马”时，服务端额外送入 `presets/shenzhen-hackathon.json` 的场地、活动和角色说明，并上传 `presets/assets/venue.jpg` 与 `presets/assets/tachikoma.jpg` 作为参考；观众人物和预设元素的主次依据照片判断。DeepSeek 给出人物取景、地点依据、文字处理、配件遮挡四项可核对的决策；默认保留半身，不虚构腿脚。仍需人工核对地标、角色和打印效果。
- 参考图独立保存历史，核对后点击“参考图满意，生成三维”；可从历史参考图继续，无需重新生图。数字模型保留源纹理，打印颜色按耗材设置另行处理。GLB 要求内嵌、未压缩静态三角网格；开放或断开的实体拒绝导出，不替换成拱廊。无自动付费重生成。
- 参考图直接交给 Tripo 的图生三维接口，不另传故事提示词。返回的 GLB 在本地校正朝向、按宽度等比缩放，保留原模型背面，不额外增加轮廓背板或切磁铁孔。仍检查封闭、连通、颜色和悬空；大面积向下悬空面会阻止导出，需在切片器核对支撑。封闭拓扑检查不能识别所有人物/背包穿插。旧历史作品需点“应用制作规格”重新整理，才会去掉此前添加的背板。
- “本地结构试制”：固定拱廊模板和本地规则，不调用 AI。手动加载试样会实际移除 1 mm 细装饰并复检，页面明确标注其来源。旧版浮雕入口保留用于历史和效果对照，旧版不含磁铁槽。
- 全局薄壁、精确支撑路径、视觉相似度、换色次数、耗材与时间尚未自动评估；悬空检查只按背板以上的向下面积保守筛查，几何检查通过不等于打印保证。先导入切片器并试打。
- 新立体记录保存几何、版本、制作规格、检查轨迹和原 GLB（如有），刷新/服务重启后可打开，并可按新宽度或颜色重新整理模型。使用同一浏览器和同一访问地址。

依赖 manifold-3d 处理实体布尔运算，@gltf-transform/core 读取内嵌 GLB，sharp 解码有界纹理，fflate 打包 3MF。运行前先执行 npm install。

## 启动

需要 Node.js 24.5+，首次运行先执行 `npm install`。

1. 在本地 `.env` 填写 `DEEPSEEK_API_KEY` 和 `TRIPO_API_KEY`，不要提交密钥。旅行回忆画的策展与成图定位使用 DeepSeek，整体生图和立体制作使用 Tripo；本机抠图不需要额外密钥。示例见 `.env.example`。
2. 运行 `npm start`，打开 http://localhost:4173 使用专业版，或打开 http://localhost:4173/simple.html 使用简洁版；页顶可直接切换版本。两版共用生成流程与当前浏览器的作品记录，简洁版默认以陶瓷风格自动生成三维。修改密钥后重启服务。
3. `npm test` 运行自动检查。

简洁版标题使用 [Noto Serif SC](https://github.com/google/fonts/blob/main/ofl/notoserifsc/METADATA.pb)，正文使用 [Noto Sans SC](https://github.com/google/fonts/blob/main/ofl/notosanssc/METADATA.pb)，两者均为 SIL Open Font License；页面通过 [Google Fonts CSS API](https://developers.google.com/fonts/docs/css2) 加载，离线时回退到系统字体。

DeepSeek 默认 `deepseek-flash`。Tripo 生图默认 `chat_image_2.5_sunburst`；也可改为 `chat_image_2.5_flare`（更快）。旅行整画需要这两个 GPT Image 2.5 型号之一。每次用户主动生成或重绘会消耗平台额度。参考 [Tripo v3 图像编辑文档](https://developers.tripo3d.ai/en/docs/generation-image-to-image)。

## 旧版浮雕使用

- 上传照片或选择主题预设，故事、地点、日期选填。可用原生文件选择、拖入、Ctrl+V 粘贴、相机拍摄添加照片；图片旁显示读取结果。支持 JPG / PNG / WebP，20 MB 内、4800 万像素内，压缩到最长边1600。HEIC 请先转换成 JPG。
- 旧版模式入口位于“开发选项”；默认 3D 创作仍要求照片。作品标题由 AI 构思，只保存为记录，不刻进作品。
- 点击生成：人物和地标由生图模型绘制。默认 3D 参考图不加名牌、日期票根或小字；重绘可以修正画面内容。
- 在「彩色成品效果」「白色试打效果」「原始设计图」间切换。拖动模型旋转；Ctrl+滚轮缩放，普通滚轮滚动页面。
- 在「调整白色浮雕层次」中调节高度和平滑度。保存彩色设计 PNG，导出白色打印 STL。
- 「生成历史」默认收起，自动保存每次成功生成、重绘和本地照片直转的作品，按生成时间倒序显示。展开后可打开作品，恢复故事、地点、日期、风格、参考照片和浮雕参数，继续修改或导出 PNG / STL；调整浮雕参数会更新该记录。删除记录不会清空当前预览。
- 历史存于当前浏览器的 IndexedDB，刷新页面、重启服务后仍可查看；需使用同一浏览器和访问地址（域名、端口均相同）。不跨设备同步，清除网站数据会删除记录；保存失败会明确提示，请导出重要作品备份。新增功能之前未保存的作品无法自动找回。
- 「直接把照片转浮雕」是非 AI 本地转换，不声称重绘了照片。默认故事创作不会加载固定地点样图。
- 等待 Tripo 时可停止等待；已提交的云端任务可能继续。提交响应会保留任务编号，再停止轮询；点击「继续取生成结果」取回同一个任务，避免重新付费。页面刷新/服务重启后，本地任务恢复入口不保留。

## 旧版浮雕边界

模型沿图案外轮廓生成一个连通的平背实体，自动填充内部孔洞、丢弃孤立小片。默认宽60 mm，底板2 mm，浮雕上限1.6 mm；高度随原图比例变化。它是从色彩明暗平滑构造的**艺术浅浮雕**，不是深度扫描，也不是 Tripo 自由立体模型生成。彩色纹理和几何分开处理，切换颜色不改变可打印网格。

STL 不含颜色和单位，导入 Bambu Studio 时按毫米确认尺寸。当前白色 A1 只打印几何；细字、五官、线条和打印时间需切片及实物验证。背面粘磁铁；没有磁铁槽或自动控制打印机。

上传文件只在用户点击 AI 生成时传给 DeepSeek / Tripo。本地服务不落盘保存用户照片，云端任务结果短暂留在服务内存；已成功生成的作品、输入文字和压缩参考照片会保存在当前浏览器的历史中。未完成的云端任务恢复入口仍不支持刷新或服务重启。开发验证截图与模型报告位于 git 忽略的 `artifacts/`。

浏览器回归检查：安装或使用现有 Playwright，并让 `NODE_PATH` 指向其所在的 `node_modules`，运行 `node tests/history.browser.js`（需要 Chrome）。检查使用本地样图和模拟接口，不消耗 API 额度，覆盖历史保存、刷新恢复、参数与照片恢复、STL 导出、重绘、删除、移动端和存储失败；`npm test` 继续运行无依赖的基础检查。

服务仅绑定127.0.0.1，密钥留在服务端，静态资源使用白名单。启动已启用 Node 的原生环境代理支持，沿用机器的 HTTP_PROXY / HTTPS_PROXY。本机国际 Tripo 域名需要已有代理连接。Codex 受限环境可能阻止 Node 出网；应使用已获授权的联网进程启动服务。普通本机终端运行 `npm start` 即可。
