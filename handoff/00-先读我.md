## 队友首次启动

安装 Node.js 24.5 或更新版本，先解压整个文件夹，再在项目根目录打开 PowerShell。

~~~powershell
node --version
npm ci
Copy-Item -LiteralPath .env.example -Destination .env
npm start
~~~

本包的 .env.example 使用 PORT=4180。旅藏入口：http://localhost:4180/travel.html；原有照片创作入口：http://localhost:4180/ 。如果不复制模板，服务默认4173。端口被占用时，在自己的.env里改 PORT；浏览器记录按域名和端口隔离，换地址会看到另一份本机记录。

没有密钥也可运行旅藏本地示范。需要 AI 时在本机.env填写 DEEPSEEK_API_KEY；图片或云端3D创作还需 TRIPO_API_KEY。包里没有实际密钥，不要把.env提交到GitHub。复制配置文件前确认队友目录尚无自己的.env。

首选本地示范验证路线、3D旋转、收藏、分享、STL和报价。页面配置了 DeepSeek 时默认AI，打开页面不会自动发起收费生成；点击发送或生成才可能调用外部服务。不要把自动化真实调用脚本当成免费单测。

~~~powershell
npm test
node tests/travel-chat.browser.js
node tests/workspace.browser.js
node tests/workspace-recovery.browser.js
node tests/travel.browser.js
~~~

浏览器检查需要本机 Chrome。npm ci需要联网下载依赖。旧版照片合集的本机抠图首次需要下载模型，有代理需求时沿用本机环境；这些缓存未打包。主旅藏示例不依赖抠图模型。
